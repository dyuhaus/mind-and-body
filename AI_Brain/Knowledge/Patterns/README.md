# Patterns

Reusable technical patterns used across one or more projects. File naming: lowercase, hyphenated (e.g., `repository-pattern.md`, `event-sourcing.md`, `circuit-breaker.md`).

## Template

```markdown
# <Pattern Name>

## Purpose
[What problem the pattern solves]

## Structure
[Core components and their roles]

## When to Use
- [condition 1]
- [condition 2]

## When Not to Use
- [anti-pattern indicator 1]

## Example
[Minimal code or diagram]

## Related Projects
- [[Projects/ProjectName/ProjectName_architecture]]
```
