# Knowledge

Domain knowledge, patterns, and references that apply across projects.

## Subdirectories

- **`APIs/`** — Reference notes for external APIs the system integrates with. One file per API (e.g., `openai.md`, `stripe.md`).
- **`Patterns/`** — Reusable technical patterns (algorithms, architectures, evolutionary strategies, etc.).
- **`Tools/`** — Notes on tools, frameworks, and discoveries (e.g., new libraries, research findings, integration tips).

## Adding Entries

When the Body encounters a new API, pattern, or tool worth documenting, it sends the information to the Mind. The Mind creates the appropriate file and links it from `_Index.md` and from any related project `overview.md` or `architecture.md`.
